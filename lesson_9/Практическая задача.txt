За пример рекомендую взять таблицу, функцию и скрипт питона, которые имеются в репозитории занятия № 9.

Формулировка задачи:

1. Создать таблицу, которая будет использоваться для логирования проводимых проверок.
2. Реализовать процедуру, которая при запуске производит поиск следующих проблем в данных:

--Есть транзакции, у которых id магазина is null.
--Есть транзакции, у которых id кастомера is null.
--Есть магазины, для которых не задан город.

3. Осуществить вызов процедуры через оператор call. ( call data_check_proc(); )
4. Написать скрипт на питон который подключается к бд забирает НЕ ОТПРАВЛЕННЫЕ сообщения и выводит на экран. Предусмотреть ваариант, когда неотправленных сообщений нет.
5. Доработать скрипт так, чтоб не приходилось руками запускать процедуру. 
6. Добавить отправку уведомлений в ТГ канал. (если машина работает без соответствующего ПО, то из-за блокировок отправить сообщение в ТГ не получится)
7. Автоматизировать запуск скрипта с помощью Планировщика задач (Windows) либо Cron (*Unix). Для Windows рекомендую использовать bat файл аналогичный тому, что приложен в репозиторий. 
Учитывайте версию питона, которая установлена в вашей системе. Если установлена только одна версия, то вместо py -3.9 можно заменить на python.

PS. Все пароли, токены и прочие чувствительные данные рекомендую прописывать в файле .env который кладется в одну папку с python-скриптом.

Для планировщика ипользуем следующий алгоритм - открыть Планировщик -> Создать задачу (не простую задачу, а задачу)-> даем имя задаче -> вкладка Триггеры -> устанавлияваем условия запуска -> вклада Действия -> Создать -> Запуск программы -> Обзор -> указываем наш файл bat -> вкладки Услови и Настройки выставляем на свое усмотрение.
Слева нажать на папку Библиотека планировщика задач -> увидим в центральном верхнем окне задачи. находим свою и ждем запуска, либо клик правой кнопкой мыши  -> Выполнить.

Для cron:
пишем в терминале:
crontab -e

Указываем в какое время и что делать (что за звездочки можно спросить у гугла https://crontab.guru/)
0 * * * * python3 /home/user/scripts/script.py

Все.
