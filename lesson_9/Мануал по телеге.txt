ДИСКЛЕЙМЕР: ТОКЕН И CHAT_ID НЕ ЯВЛЯЮТСЯ ДЕЙСТВУЮЩИМИ.

Как создать канал для отправки уведомлений в ТГ:

1. Создать канал в ТГ.
2. Создать бота через @BotFather. После регистрации он выдаст токен. Токен нужно сохранить и никому не показывать.
3. CHAT_ID можно получить из строки в браузере, если открыть канал, например:
https://web.telegram.org/a/#-1002105169120   здесь CHAT_ID = -1002105169120;
либо написать в свой канал любое сообщение, а потом переслать его боту - @raw_data_bot

тестировать отправку можно через браузер. просто в адресную строку вставить следующую строку:
К примеру такой запрос:
тут адрес АПИ телеги----|дальше идет токен бота --------------------------|--------------------тут id чата----|тут текст сообщения--------------|
https://api.telegram.org/bot6931153014:AAEP-rhF7C9__821XIjRo6eaHas1T1_apaM/sendMessage?chat_id=-1002125369121&text=Какой-то_текст&parse_mode=HTML

возвращает такой ответ:

{"ok":true,"result":{"message_id":309,"sender_chat":{"id":-1002105169120,"title":"DMP alerts test","type":"channel"},"chat":{"id":-1002105169120,"title":"DMP alerts test","type":"channel"},"date":1765437411,"text":"TEXT"}}

Ключ "ok":true означает, что отправка успешная, далее идут различные параметры сообщения, название канала и тд.

Для внедрения в код питона рекомендую использовать библиотеку requests

import requests 

token = 6931153014:AAEP-rhF7C9__821XIjRo6eaHas1T1_apaM
chat_id = -1002125369121
message_text = "Текст, который надо отправить"

requests.post(f'https://api.telegram.org/bot{token}/sendMessage?chat_id={chat_id}&text={message_text}&parse_mode=HTML')
